# 嗨，我是哲偉（tako）

在花蓮念東華資工，大三。

我剛開始寫交易回測的時候，程式不小心偷看到了未來的資料，回測績效漂亮到不行，我還真的信了好一陣子。從那次之後，看到很厲害的數字我都會先懷疑一下。X 上那些曬績效的文我也拆過幾篇，大部分是倖存者偏差，或數字根本對不起來。

後來開始大量用 LLM。一開始只是好奇它到底是 prompt 堆出來的東西，還是真的是新概念，用久了比較在意的變成：它講錯的時候，我要怎麼知道？跟 Claude Code 一起做了一堆東西之後回頭看，才發現回測、agent 評測、重現論文，其實都在問同一件事。
