# 哲偉（tako）

東華大學資工系大三。

剛開始寫交易回測時，我的程式讀到了未來的資料，回測績效很好看，我也信了一段時間。之後看到漂亮的數字，我會先找它哪裡可能有問題。X 上曬績效的文章我拆過幾篇，多半是倖存者偏差，或數字對不起來。

後來開始大量使用 LLM。起初是好奇它到底只是 prompt 堆出來的東西，還是真的新概念；用久了，比較在意的是它出錯時要怎麼發現。跟 Claude Code 一起做了一些東西之後回頭看，回測、agent 評測、論文重現，處理的其實是同一個問題。
