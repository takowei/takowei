# 哲偉 (tako)

東華大學資工系，預計 2028 畢業。

我在意的問題是：一個系統對自己的說法，要怎麼確認是真的。剛開始寫量化回測時，我的程式讀到了未來資料，績效看起來很好，其實是假的。後來做的東西大多跟這件事有關：回測引擎強制時間落後、AI agent 評測的統計檢定、重現論文的實驗結果，還有檢查一個 GitHub repo 能不能信任。

## 公開專案

- [repovet](https://github.com/takowei/repovet)：依賴一個 repo 之前先做信任體檢（維護狀態、星數異常、不存在的套件）
- [pylsm](https://github.com/takowei/pylsm)：從零寫的 LSM-tree 鍵值儲存引擎，含 MVCC 交易
- [pricewatch](https://github.com/takowei/pricewatch)：多使用者降價提醒服務（FastAPI + PostgreSQL）
- [chain-sec](https://github.com/takowei/chain-sec)：以 Slither 為基礎的智能合約靜態分析

研究中（未公開）：大學部畢業專題（中職投手執行力量化）、AI agent 評測嚴謹性工具、RoCo 算力公平性重現。
